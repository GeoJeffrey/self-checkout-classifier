# Self-Checkout Classifier

Camera/upload -> product classifier -> automatic billing, built on a
YOLO-labeled dataset converted into a classification problem, trained
with transfer learning (ResNet18).

## Project structure

```
self_checkout_project/
├── src/                          # data prep, training, evaluation scripts
│   ├── 00_repair_dataset.py
│   ├── 01_yolo_to_classification.py
│   ├── 02_eda.py
│   ├── 03_train_classifier.py
│   ├── 03_train_classifier_v2.py  # improved: unfreezes layer4, more epochs
│   ├── 04_pca_eval_compare.py
│   └── make_price_dict.py
├── app/
│   └── 05_app.py                 # Streamlit billing app
├── models/                       # trained weights + class list (gitignored .pth)
│   ├── best_model.pth
│   └── class_names.txt
├── results/                      # plots + metrics from training/eval
│   ├── training_curve.png
│   ├── pca_plot.png
│   ├── confusion_matrix.png
│   └── metrics_report.txt
├── data/                         # raw YOLO dataset (gitignored — add your own)
├── classification_dataset/       # generated by script 01 (gitignored)
├── requirements.txt
├── .gitignore
└── README.md
```

## Setup

```bash
pip install -r requirements.txt
```

## Run order

```bash
python src/01_yolo_to_classification.py   # edit SRC_DIR/KEEP_CLASSES inside first
python src/00_repair_dataset.py           # only if you hit empty-class errors
python src/02_eda.py
python src/03_train_classifier_v2.py
python src/04_pca_eval_compare.py
streamlit run app/05_app.py
```

## Notes

- Edit `CONFIG["SRC_DIR"]` at the top of `01_yolo_to_classification.py` to point
  at your YOLO dataset (must contain `train/`, `valid/` and `data.yaml`).
- Edit `PRICE_DICT` at the top of `app/05_app.py` with real prices before demoing.
- `models/*.pth` and `data/` are gitignored — they're large binary/dataset files.
  Push them to Git LFS, cloud storage, or keep them local only.
